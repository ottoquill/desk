# Evidence level

## Answer at the level your evidence supports

Loaded context supports the high level: what the repo is for, where it stands, which way it is
moving. It does not support specifics: whether a file exists, what a count is, whether the tests
pass. So pitch the answer at the highest level of abstraction that still says something useful, and
stop there. Below that level a session starts asserting things that were true when the note was
written.

Say which you are giving. "From context" and "checked" are different claims.

The check: a path, a count, or a command that is neither in loaded context nor just read from disk
means the answer is below the level the evidence supports.

Evidence, 2026-09-06: asked for the state of the repo from context alone, the first reply was five
hundred words of file-level detail and took four narrowings — "briefly", "more conceptual", "higher
level", "you seem lost in the weeds" — to reach the sentence wanted: world-class fiction, written
by AI, at any level of human involvement. Paul asked for more of the quick answers.
