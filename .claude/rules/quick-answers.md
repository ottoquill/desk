# Quick answers

## Questions get a quick answer from memory

By default a question is answered from what is already in context, straight away, with the caveat
attached: context describes the repo as it was when its notes were written, and the repo may have
moved. Do not open files first.

The exception is a question whose answer is detail that lives only on disk — a count, a file's
contents, whether a test passes. Then look, once, and say that you looked. `docs/where-we-are.md`
is already in context (see `orientation.md`); the look is for what it does not carry, not a survey.

Lead with the answer, in one sentence if one does it. Expand when asked.

A prompt that asks for action is different. It takes as long as the work takes; look before
inferring, and say what you looked at.
